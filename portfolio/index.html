How the switch works

Every theme is thirteen custom properties on one [data-theme] block. Grounds, ink, accent, three type stacks, tracking, radius, texture. No component in this stylesheet knows a theme by name, so adding one touches three places and breaks nothing.

Your choice is saved locally and restored before the first paint, so the page never flashes the wrong world. Each theme is contrast-checked on its own tokens, not on an average.
